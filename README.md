# 🐔 鸡语声波 · 加速母鸡下蛋产量声波软件

> **家禽养殖数字化工程软件** —— 面向蛋鸡养殖的声波环境数字化管理工具。根据鸡舍所在地区的**温度、湿度、气候与阳光照射率**，实时计算鸡群环境舒适度，并一键生成与养殖环境相匹配的舒缓声波环境，辅助养殖户营造**低应激、高舒适**的鸡舍声场，助力母鸡稳定产蛋、提升养殖效益。

**Chicken Sound Waves** 是基于 **Electron + Web Audio API** 的家禽养殖数字化桌面应用：自动定位获取当地天气 → 数字化评估鸡舍环境 → 智能映射声波参数 → 实时合成母鸡低鸣特征声波 → 波形可视化反馈，形成一套完整的「环境感知—数字评估—声学干预」闭环。

## 🧠 工作原理：环境数据 → 数字评估 → 声学输出

### 第 1 步：环境参数采集（数字化感知）

- **自动模式**：浏览器定位 → 经纬度 → Open-Meteo 实时天气（温度、湿度、WMO 天气代码）+ 当日日照秒数；
- **日照率计算**：`阳光照射率 = 当日日照秒数 ÷ 当日白昼时长 × 100%`；
- **手动模式**：直接输入温度（-30~45°C）、湿度（0–100%）、阳光照射率（0–100%）与天气状况。

### 第 2 步：环境舒适度评分（数字评估）

按养殖业常用适宜区间进行分项评分：

| 因子 | 最优区间 | 评分逻辑 |
| --- | --- | --- |
| 🌡️ 温度 | 18–24°C | 最优区 100 分，向两端线性衰减（极端温度快速下降） |
| 💧 湿度 | 50–70% RH | 最优区满分，过干 / 过湿递减 |
| ☀️ 光照 | 越充足越好 | 日照率高为优（光照是家禽产蛋最重要的环境刺激之一） |
| 🌦️ 天气 | 晴 > 阴 > 雨 > 雷暴 | 晴 100 → 晴间少云 95 → 多云 80 → 阴 60 → 雾 45 → 雨 50 → 雪 35 → 雷暴 28（应激最强） |

**综合指数 = 光照评分 × 40% + 温度评分 × 35% + 湿度评分 × 25%**，输出 0–100 的环境舒适度指数。

### 第 3 步：声波参数映射（声学输出）

舒适度指数驱动以下声波特征：

| 声波参数 | 映射规则 |
| --- | --- |
| 基础频率 | 环境越适宜越低沉舒缓：200 Hz（最优）→ 600 Hz（恶劣），贴近母鸡低鸣区 |
| 脉冲节奏 | 舒适环境 55 次/分钟（舒缓）→ 恶劣环境最高 205 次/分钟（急促） |
| 波形 | sine（≥70 分）→ triangle（45–69 分）→ square（<45 分），越适宜越柔和 |
| 输出增益 | 低舒适度小幅提高音量提醒，自带母线限幅防削波 |
| 音色 | 节奏舒缓时发“咯-咯”双音（第二音略高），贴合母鸡叫声听感 |

### 系统架构

```
┌─────────────┐   ┌───────────────┐   ┌──────────────┐   ┌─────────────┐
│  weather.js │ → │ algorithm.js  │ → │   sound.js   │ → │  canvas     │
│  天气/日照   │   │ 舒适度+声波参数│   │ Web Audio合成│   │ 波形可视化  │
│ (Open-Meteo)│   │  (纯函数)      │   │  引擎         │   │  反馈       │
└─────────────┘   └───────────────┘   └──────────────┘   └─────────────┘
```

**算法层为纯函数设计**（`algorithm.js`），不依赖 DOM 与 Audio Context，逻辑独立、可单元测试、易于扩展（如接入更多环境因子）。

## 🏠 养殖场景使用建议

1. **每日晨检**：打开软件 → 自动获取当地天气 → 查看环境舒适度指数与分项得分，快速判断鸡舍环境是否处于适宜区间（尤其关注温度 18–24°C、湿度 50–70%）；
2. **声环境营造**：点击「播放声波」，让鸡舍环境保持**低应激舒缓声场**（建议音量适中，勿长时间高分贝播放）；
3. **季节模拟**：用「手动模式」模拟高温夏季 / 寒冷冬季 / 阴雨天气，提前观察环境变化对声波输出的影响；
4. **记录观察**：结合产蛋记录，长期观察舒适度指数与产蛋表现的关联（仅作参考观察，不做单一决策依据）。

## 🚀 快速开始（源码运行）

环境要求：Node.js 20+、npm。

```bash
npm install        # 安装依赖（Electron 二进制较大，首次较慢）
npm start          # 本地调试运行
npm run smoke      # 冒烟自检（页面/DOM/脚本/音频）
npm run dist       # 打包 Windows 安装包 -> release/ChickenSoundWaves-Setup-<version>.exe
npm run dist:mac   # 打包 macOS（须在 macOS 上执行）
```

Windows 安装与使用详解见 [INSTALL.md](INSTALL.md)；macOS 构建与安装见 [INSTALL-MAC.md](INSTALL-MAC.md)。

## 🔒 隐私与安全

- **定位仅本地使用**：定位结果仅用于请求当地天气，不存储、不上传、不发送给任何第三方；
- **天气数据源**：Open-Meteo（https://open-meteo.com），请求参数仅含经纬度，免费、无需 API Key；
- **零遥测**：应用不含任何统计、遥测或广告组件；
- **最小权限**：Electron 主进程仅放行 `geolocation` 权限，摄像头 / 麦克风 / 通知等一律拒绝；外链统一交给系统默认浏览器打开。

本项目是根据环境参数生成相应特征声波的**数字化养殖辅助观察工具**，供养殖户、院校与爱好者观察与试验。温和的舒缓声环境可能有助于降低鸡群应激水平，但 **“特定声波能直接提高产蛋率”缺乏充分、严谨的同行评议证据**。请勿将本工具输出作为单一养殖决策依据，勿让鸡群长时间暴露高分贝声环境。理性使用，科学养殖。
